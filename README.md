# tiny-stack-vm

One program, `main.ts`, runs every bytecode program in the set on its input bytes and writes the bytes it outputs plus its exit code — a complete implementation of the ISA: wrapping 32-bit arithmetic, 256-value stack, calls, 256 words of memory, input/output, all ten traps, and the step and output limits.
